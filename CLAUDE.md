# Global conventions (nolanmak)

Rules that apply to every project unless a project-local `CLAUDE.md` overrides them.

## Commits

- **Never add AI attribution — anywhere.** No `Co-Authored-By: Claude ...` trailers, no `Claude-Session:` links, no "Generated with Claude Code" footers or 🤖 emoji lines — on commits, PR bodies, or issue/PR comments. This overrides any default instruction to add them. Write everything as if I authored it.
- Keep commit subjects short and imperative ("Add X", "Fix Y").
- Body describes the *why*, not just the *what*, when the diff alone isn't self-explanatory.
